# Простое веб-приложение

Проект представляет собой простое веб-приложение, созданное в рамках учебного задания. Приложение обрабатывает HTTP запросы и возвращает HTML-страницы.

## Функциональность
* GET запросы: Отображение статических HTML-страниц

* / - Главная страница

* /catalog - Страница каталога товаров

* /category - Страница категории товаров

* /contacts - Страница контактов с формой обратной связи

* POST запросы: Обработка данных форм с выводом в консоль сервера

* Статические страницы: Верстка выполнена с использованием Bootstrap 5

## Структура проекта
    my_web_app/
    ├── app.py # Основное приложение (обработчик запросов)
    ├── README.md # Документация проекта
    ├── .gitignore # Файл для игнорирования ненужных файлов
    └── templates/ # HTML шаблоны
    ├── index.html # Главная страница
    ├── catalog.html # Страница каталога
    ├── category.html # Страница категории
    └── contacts.html # Страница контактов

## Запуск приложения

1. Клонируйте репозиторий
2. Перейдите в директорию проекта
3. Запустите сервер:
    ```bash
    python app.py
    ```
4. Откройте браузер и перейдите по адресу: http://localhost:8000
